# SCHOOL-ERP-LOGIN

School ERP front-end prototype with management, teacher, and student dashboards.

## Run locally
1. Open this folder in Visual Studio Code.
2. Install the Live Server extension if needed.
3. Right-click `index.html` and select **Open with Live Server**.

## Project structure
- `index.html` — page markup
- `css/style.css` — styles
- `js/app.js` — client-side demo logic

## Important
This is a front-end demonstration. Sample accounts and records are stored in JavaScript and are not secure or shared between devices. Do not use real student data or deploy as a production school system until a secure backend, database, authentication, and authorization are implemented.
